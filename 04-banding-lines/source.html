Causes 1–3: the head

1. Clogged nozzles
One or two cleanings usually fix it. White nozzles need the most care.
2. Bidirectional timing
Alternating lines? Turn bidirectional off. If they vanish, set head gap 1–3.
3. Too few passes
At 720 × 720 each nozzle's error shows. More passes hide it.

Causes 4–6: feed, ink, file

4. Media feed
Even lines one head pass wide: the film advanced too much or too little.
5. Ink starvation
Lines get worse late in a long print: low tanks, air in a tube, old dampers.
6. The file
View the file at 200%. If the bands are in the file, the printer is innocent.
